# R Programming for Economics

Welcome to my repository documenting my journey into R programming, with a focus on economics, econometrics, and data analysis.

This repository documents my work as a third-year Economics student, showcasing the application of R programming to econometric analysis, statistical modeling, and empirical economic research. It includes code developed across various topics in economics and econometrics, with a primary focus on regression-based analysis, model diagnostics, hypothesis testing, and statistical inference. I also use this space to document independent research, subject-based analytical projects, and empirical investigations exploring economic relationships through data. The repository serves as a growing collection of my analytical work, computational methods, and applications of quantitative techniques to economic questions.
